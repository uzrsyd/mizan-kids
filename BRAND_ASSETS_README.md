# Mizan Kids Claude Brand Pack — Full Visual Library

Place the contents of this package at the root of the `mizan-kids` project before opening the project in Claude Code.

## Included

### `/brand-reference`
Contains all **49 current Mizan Kids visual reference PNGs**, numbered MK-001 through MK-049. These are design references and should be preserved unchanged.

### `/public/brand`
Contains approved production-facing logo/brand assets for use by the website where appropriate.

### `CLAUDE_BRAND_INSTRUCTION.md`
A short instruction file reinforcing how Claude should interpret and preserve the supplied assets.

## Preservation rule

Claude must scaffold/build the application around these existing assets. It must not overwrite, delete, move, rename, or destructively optimize the originals without explicit approval.
