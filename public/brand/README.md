# Public Brand Assets

These files can be served by the Next.js application from `/public/brand`.

Recommended use:
- Header/nav: `logo-wordmark-transparent.png`
- Footer/about: `logo-full-transparent.png`
- Compact mark/favicon: `brand-mark-transparent.png` or `favicon-512.png`
- Default Open Graph preview: `og-default.png`
- Early Access page/social preview: `og-early-access.png`

Do not stretch the raster logo beyond what is visually clean.
A final SVG/vector logo pack should eventually replace the extracted PNG logo assets.
