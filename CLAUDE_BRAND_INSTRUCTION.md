# Claude — Mizan Kids Brand Instructions

Before designing or coding UI:

1. Inspect all files in `/brand-reference` and `/public/brand`.
2. Treat the supplied Mizan Kids logo direction and visual language as approved starting brand direction.
3. Extract recurring colors, typography, spacing, card shapes, illustration language, photography treatment, educational motifs, and CTA patterns into reusable design tokens/components.
4. Do not turn the website into a collage of social posts. Translate the underlying brand language into a refined, responsive product experience.
5. Do not replace the brand with a generic SaaS visual system.
6. Preserve all original files in `/brand-reference` and `/public/brand` unchanged. If optimized/derived versions are needed, create new files instead of overwriting originals.
7. If project scaffolding would conflict with an existing file, preserve the existing user file and explain the conflict before proceeding.
