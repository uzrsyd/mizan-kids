# Mizan Kids Brand Reference Library

This folder contains the complete current Mizan Kids visual reference library: **49 PNG designs (MK-001 through MK-049)**.

Claude should inspect these images as brand/design references before proposing the website design system. They establish the visual language across brand, Quran, Arabic, Salah, Seerah, Duas, Akhlaq, parent progress, Early Access, Ramadan, and informational/editorial content.

## Important

- Treat these files as source/reference assets.
- Do not delete, rename, overwrite, recompress, crop, or otherwise modify the originals.
- Do not assume every image should appear directly on the website.
- Extract recurring brand principles from the full library and translate them into a coherent responsive web/app design system.
- If a derivative or optimized asset is needed, create a new file and preserve the original.
- Production logo and web assets live separately under `/public/brand`.
